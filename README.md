# Khalid Parekh — Personal Brand Website

## Preview

```bash
cd /Applications/Projects/Office/kp
python3 -m http.server 8080
```

## Menu → Routes

| Menu | Public route |
|------|--------------|
| Home | `/` |
| About | `/about/` |
| Press & News | `/press/` |
| Leadership & Vision | `/leadership/` |
| Blog | `/blog/` + `/blog/<slug>/` |
| Store | `/product/` |
| Contact | `/contact/` |

## Typography

- Headings: **Cormorant Garamond**
- Body: **Source Sans 3**
- Brand accent: crest crimson `#C8102E`
